# Registro de fuentes

| Fuente | Uso previsto | Estado |
|---|---|---|
| [DEIS, nacidos vivos 2014-2024](https://www.argentina.gob.ar/salud/deis/datos/nacidosvivos) | Base principal | Descargada, catalogada y auditada |
| DEIS, diccionario de nacidos vivos | Diccionario y códigos | Descargado y validado |
| [DEIS, Estadísticas Vitales 2024](https://www.argentina.gob.ar/sites/default/files/serie_5_nro_68_anuario_vitales_v4_revisada_ok.pdf) | 41 controles y advertencias metodológicas | Conciliada sin diferencias |
| [DNP, Natalidad y educación en Argentina (2025)](https://www.argentina.gob.ar/sites/default/files/2025/08/natalidad_y_educacion_en_argentina._perspectivas_a_futuro._-_2025.pdf) | Contexto de relevancia y control de originalidad | Auditada; sus series RENAPER no se empalman con DEIS |
| [INDEC, Censo 2022](https://www.indec.gob.ar/indec/web/Nivel4-Tema-2-41-165) | Contexto de estructura demográfica | Consultado; no usado como denominador retrospectivo |
| [INDEC, proyecciones 2022-2040](https://www.indec.gob.ar/indec/web/Nivel3-Tema-2-24) | Evaluar denominadores poblacionales | Consultadas; comienzan en 2022 y no cubren la serie completa |
| [Bases de Contar con Datos 2026](https://www.udesa.edu.ar/contar-con-datos) | Requisitos, entrega y rúbrica | Consultada y traducida a estrategia |

Toda incorporación deberá registrar URL exacta, organismo, fecha de descarga,
licencia o condiciones de reutilización, formato, cobertura y checksum.

La comparación y las reglas para no mezclar universos están documentadas en
`docs/context-source-review.md`.
