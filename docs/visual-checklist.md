# Checklist de validación visual

Ninguna exportación se considera lista hasta completar este control.

## Evidencia

- [ ] La afirmación principal está respaldada por una tabla reproducible.
- [ ] Cantidades, tasas y porcentajes están claramente diferenciados.
- [ ] Cada tasa declara su denominador.
- [ ] Las comparaciones utilizan períodos y universos equivalentes.
- [ ] Se revisaron faltantes, categorías sin especificar y valores atípicos.
- [ ] Se buscaron casos que contradicen la interpretación principal.
- [ ] No se utiliza lenguaje causal sin diseño causal.
- [ ] Las proyecciones están identificadas como proyecciones.

## Representación

- [ ] El tipo de gráfico corresponde a la escala de medición.
- [ ] La codificación más precisa se reserva para la comparación principal.
- [ ] El orden de los datos responde a la pregunta y no a una convención inútil.
- [ ] La agregación no oculta un patrón relevante del nivel inferior.
- [ ] El área o el volumen no sustituyen una comparación que exige longitud o
      posición.
- [ ] El color tiene significado consistente y no es la única señal disponible.

## Narrativa

- [ ] La idea principal puede expresarse en una frase.
- [ ] La lectura inicial requiere menos de diez segundos.
- [ ] Cada panel añade información nueva.
- [ ] Título, subtítulos y anotaciones expresan hallazgos, no temas genéricos.
- [ ] La conclusión reconoce matices y evita alarmismo.

## Diseño

- [ ] La evidencia tiene mayor peso visual que la decoración.
- [ ] Escalas compartidas y alineaciones permiten comparar.
- [ ] Tipografía, espaciado y jerarquía son consistentes.
- [ ] Texto y gráficos son legibles al tamaño real de entrega.
- [ ] La paleta supera una revisión de contraste y visión cromática.
- [ ] No hay texto cortado, solapamientos, glifos dañados ni imágenes borrosas.

## Transparencia

- [ ] Las fuentes aparecen completas y verificables.
- [ ] Se indican fecha de descarga y versión de los datos.
- [ ] Se explicitan transformaciones y exclusiones importantes.
- [ ] Las limitaciones metodológicas están visibles.
- [ ] El uso de IA está registrado y es compatible con las bases.

## Entrega

- [ ] El archivo corresponde a PNG, JPG, GIF o PDF.
- [ ] La visualización tiene título y descripción.
- [ ] Se utiliza seudónimo en la obra.
- [ ] La descripción metodológica no supera 200 palabras.
- [ ] El archivo final fue renderizado e inspeccionado página por página.
