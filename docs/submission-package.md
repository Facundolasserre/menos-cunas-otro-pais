## Breve descripción metodológica

<!-- BEGIN FORM DESCRIPTION -->
Se analizaron los datos abiertos de nacidos vivos publicados por la Dirección de
Estadísticas e Información de la Salud (DEIS) para 2014–2024: 133.716 registros
tabulares que representan 6.722.956 nacimientos registrados. Los archivos fueron
descargados sin modificación, normalizados en un esquema común y conciliados con
41 controles del Anuario de Estadísticas Vitales 2024. No se eliminaron ni
imputaron observaciones; las anomalías quedaron preservadas y documentadas. Para
comparar edades se excluyeron únicamente los casos con edad materna desconocida
del denominador correspondiente.

La historia visual separa conteos de composiciones y evita presentarlos como
tasas de fecundidad. Una serie muestra la trayectoria nacional; diagramas de
puntos emparejados comparan 2014 y 2024 por edad y jurisdicción sobre escalas
comunes. La proyección educativa final proviene de un informe DNP/RENAPER y se
identifica como contexto externo.

Se utilizó OpenAI Codex para explorar alternativas, asistir en programación,
validar datos y revisar textos y accesibilidad. Cada resultado fue contrastado
con las fuentes y revisado iterativamente por el autor. No se utilizaron
generadores de imágenes ni se delegaron a IA las decisiones finales de análisis,
narrativa o diseño.
